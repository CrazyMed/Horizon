Eli Lilly's Phase 3 TRIUMPH-1 trial demonstrated that retatrutide, a triple GIP/GLP-1/glucagon receptor agonist, achieved an average of 28.3% body weight reduction at the 12mg dose over 80 weeks, with 45.3% of participants losing at least 30% of their body weight. This represents the highest average weight loss reported in a Phase 3 obesity trial to date, potentially establishing retatrutide as a best-in-class treatment for obesity. The trial enrolled approximately 2,500 obese or overweight adults with at least one weight-related comorbidity. The 4mg dose group showed 19.0% average weight loss. Discontinuation due to adverse events was 4.1%, lower than the 4.9% rate in the placebo group. Common side effects were primarily gastrointestinal in nature, and no cardiac or liver safety signals were observed.

GLP-1 agonists like semaglutide (Wegovy) have already demonstrated significant weight-loss efficacy. The triple agonist mechanism aims to tackle obesity through multiple pathways simultaneously.

## [Deno 2.8 Release Sparks JS Runtime Ecosystem Debate](https://deno.com/blog/v2.8) ⭐️ 6.0/10

Deno released version 2.8, generating 132 Hacker News comments that debated the competitive JavaScript runtime landscape. The discussion centered on Deno's permission model advantages versus Bun's speed, and Deno's improving Node.js compatibility (now approximately 75%). This release highlights the intensifying competition between JavaScript runtimes. With Bun's acquisition by Anthropic and increased focus on Node.js compatibility across runtimes, developers face important choices about which runtime to adopt for future projects. Deno's permission model provides granular runtime security through explicit permission flags for network, file system, and environment access. The community noted that Edge.js's release coincided with Deno's Node.js compatibility improving from approximately 40% to 75% over two months.

hackernews · roflcopter69 · May 22, 11:23 · [Discussion](https://news.ycombinator.com/item?id=48234380)

**Background**: JavaScript runtimes execute JavaScript code outside web browsers, with Node.js as the established industry standard since 2009. Deno (2018) brought security through sandboxing and native TypeScript support. Bun (2022) entered the market emphasizing speed and an all-in-one approach. Each runtime is actively pursuing Node.js compatibility to ease migration paths for existing projects.

## [Antigravity 2.0 Leads OpenSCAD Architectural 3D LLM Benchmark](https://modelrift.com/blog/openscad-llm-benchmark/) ⭐️ 6.0/10

A new OpenSCAD benchmark tests six LLMs on recreating the Pantheon in 3D, with Google Antigravity 2.0 achieving top results. Notably, Antigravity was the only autonomous agent that implemented the Pantheon's signature interior ceiling pattern of repeated square coffers visible through the oculus. This benchmark demonstrates emerging practical capabilities for LLMs in parametric 3D CAD modeling, a domain requiring precise, structured code generation. The results highlight both the potential and current limitations of AI-assisted CAD workflows for makers, engineers, and designers who rely on script-based modeling tools. The benchmark compared Codex 5.5 High, Claude Sonnet, Claude Opus, Cursor Composer, Google Antigravity, and ModelRift. Community reviewers note that a single architectural model test may not be representative of general CAD capabilities, as different LLMs excel at different 3D modeling tasks and may produce jagged or inconsistent results.

**Background**: OpenSCAD is a free, script-based 3D CAD software that functions as a '3D compiler' rather than an interactive modeler. Unlike artistic tools like Blender, OpenSCAD uses its own description language to define parametric models through constructive solid geometry (CSG) operations and 2D extrusion. The Pantheon, built around 126 AD in Rome, features a iconic coffered dome with a central oculus—the benchmark tasks AI models with recreating this architectural complexity in OpenSCAD code.

## [Memory Shortage Reshaping Consumer Electronics Pricing](https://simonwillison.net/2026/May/22/memory-shortage/#atom-everything) ⭐️ 6.0/10

Memory manufacturers are redirecting wafer capacity from consumer-grade memory (DDR/LPDDR) to high-bandwidth memory (HBM) for AI data centers, with HBM allocation expected to reach 20% of total wafer capacity by end of 2026, up from just 2% previously. Since HBM consumes more than three times the wafer capacity per gigabyte compared to DDR or LPDDR, this shift reduces overall memory supply for smartphones and other consumer devices, driving up prices—particularly for sub-$100 devices critical to emerging markets in Africa and South Asia. The industry consolidation has left only three major memory manufacturers, making supply decisions highly concentrated. These companies historically under-provision fab capacity to avoid the mistakes that led to rival bankruptcies, meaning HBM's higher profit margins will likely constrain consumer RAM production for several years despite increased demand.

rss · Simon Willison · May 22, 22:01

**Background**: HBM (High Bandwidth Memory) is a 3D-stacked memory architecture designed for high-throughput applications like AI GPUs and high-performance computing. DDR (Double Data Rate) remains the standard for desktops and servers, while LPDDR (Low Power DDR) is optimized for mobile devices requiring energy efficiency. The wafer fabrication process for HBM is more complex and capacity-intensive than traditional memory types, explaining why it consumes significantly more wafer resources per unit of storage.
