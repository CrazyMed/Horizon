## [OpenAI 模型证伪离散几何核心猜想](https://openai.com/index/model-disproves-discrete-geometry-conjecture/) ⭐️ 8.0/10

OpenAI 的 o1 模型通过找到一个反例证伪了离散几何领域的一个核心猜想（具体与 Erdős 的原始研究相关），取得了真正的数学突破。该证伪结果附有数学家们的评论发表，其中包括菲尔兹奖得主 Tim Gowers 的见解，引发了关于 AI 辅助数学发现本质的实质性哲学讨论。 这代表了 AI 在数学研究领域的一个重要里程碑，表明大型语言模型能够为真正的数学发现做出贡献，而不仅仅是模式匹配或数据插值。这挑战了关于 AI 在创造性数学推理方面局限性的长期假设，并引发了关于数学中什么构成"发现"的深刻问题。 该模型通过找到一个反例而非构建肯定性证明来证伪猜想。一些数学家指出，发现反例在理论上的趣味性略低于证明猜想成立，因为后者需要通过更深入的理论构建来解释猜想成立的原因。结果发布时附有数学家们撰写的详细回应文章。

hackernews · tedsanders · 05月20日 19:05 · [社区讨论](https://news.ycombinator.com/item?id=48212493)

**背景**: 离散几何是数学的一个分支，研究由离散单位（如点、线和多边形）组成的几何结构，区别于连续曲线。猜想是一个被认为可能是真的但尚未被证明的数学陈述；一旦被证明，它就成为定理。在数学中，证伪一个猜想只需要找到一个表明该猜想为假的反例。已故数学家 Paul Erdős 以提出大量组合学和几何学领域的重要猜想而闻名。

## [Mozilla 在 SpiderMonkey 中弃用 asm.js，标志一个时代终结](https://spidermonkey.dev/blog/2026/05/20/saying-goodbye-to-asmjs.html) ⭐️ 8.0/10

Mozilla 已正式在 SpiderMonkey JavaScript 引擎中弃用 asm.js 支持，标志着一项曾使 Web 应用获得接近原生性能、并为 WebAssembly 铺平道路的技术的终结。 asm.js 是一个严格的 JavaScript 子集，设计作为通过 Emscripten 将 C/C++代码编译为优化目标的语言。与 WebAssembly 不同，asm.js 代码仍需要解析为抽象语法树（AST）且包体积更大。SpiderMonkey 中的这一弃用发生在 WebAssembly 于 2019 年成为 W3C 推荐标准之后。

hackernews · eqrion · 05月20日 12:01 · [社区讨论](https://news.ycombinator.com/item?id=48206340)

**背景**: SpiderMonkey 是 Mozilla 的开源 JavaScript 和 WebAssembly 引擎，为 Firefox 及其他项目提供支持，也是 Brendan Eich 在网景公司创建的第一个 JavaScript 引擎。asm.js 由 Mozilla 于 2013 年在 Firefox 22 中推出，作为一个高度可优化的 JavaScript 子集。WebAssembly 于 2015 年宣布，2019 年 12 月成为 W3C 推荐标准。asm.js 现已被视为已被 WebAssembly 超越，后者提供了用于更好性能和更小文件体积的二进制指令格式。
